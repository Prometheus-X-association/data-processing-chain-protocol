# MAINTENANCE

## Project

- **Project:** Data Processing Chain Protocol (DPCP)
- **Programme:** Prometheus-X
- **Maintainer organisation:** Visions
- **Repository:** https://github.com/Prometheus-X-association/data-processing-chain-protocol

## Maintenance Commitment

Visions commits to maintaining the Data Processing Chain Protocol for a period of **12 months following the official end of the project**.

- **Status during this period:** Actively maintained

## Scope of Maintenance

During the maintenance period, Visions will provide:

1. **Corrective maintenance:** triage and fix of reported bugs and malfunctions.
2. **Security maintenance:** monitoring and update of vulnerable dependencies, and handling of security issues in line with [SECURITY.md](SECURITY.md).
3. **Compatibility maintenance:** minor updates required to keep the software working with supported runtime versions and with the Prometheus-X ecosystem components it depends on.
4. **Documentation upkeep:** keeping the documentation consistent with the released versions.
5. **Release management:** publication of patch releases (semantic versioning) with changelog entries when needed.

**Out of scope** (unless otherwise agreed): development of major new features, and support for forks or unofficial modifications.

## Issue Handling

- Issues and bug reports are submitted through GitHub Issues
- Target acknowledgement time: **within 10 working days**.
- Critical security issues are prioritised and handled as per [SECURITY.md](SECURITY.md).

## End of Maintenance

At the end of the 12-month period, Visions will either:

- announce an extension of the maintenance commitment, or
- update this file to reflect the new status (e.g. *maintenance mode*, *looking for maintainers*, or *archived*), and communicate it in the README and via a GitHub release/announcement.
